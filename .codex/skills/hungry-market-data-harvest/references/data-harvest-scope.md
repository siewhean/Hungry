# Hungry Data Harvest Scope

This skill covers:

- venue and mall source discovery
- public store-directory extraction
- normalization into Hungry-compatible structures
- menu/OCR-derived enrichment
- source confidence and residual cleanup notes

## Preferred pipeline

1. source discovery
2. extraction
3. normalization
4. dedupe
5. confidence tagging
6. handoff to supply or fixture workflows

## Keep separate

- raw source collection
- OCR extraction output
- consumer-facing curated data
- merchant-facing supply queue
