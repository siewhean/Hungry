# Hungry Merchant Copy Pack

Use this skill when you need merchant copy that is clear, believable, and matched to the actual workflow.

## Workflow

1. Read `references/merchant-copy-surfaces.md`.
2. Identify the exact surface and merchant stage:
   - CTA
   - verification explainer
   - FAQ
   - pending / approved / rejected state
3. Match the copy to the actual operational flow, not an imagined one.
4. Produce concise copy options with one recommended version first.
5. Include constraints if the copy is gated by legal, ops, or verification reality.

## Rules

- Keep copy aligned to real Hungry workflows.
- Do not imply instant verification unless that flow exists.
- Avoid generic B2B/SaaS phrasing.
- Prefer trust and clarity over hype.
- Write for Singapore merchant context, but keep the wording broadly professional.

## Output

- surface
- audience stage
- recommended copy
- 1 to 2 alternatives if helpful
- notes on risk or operational dependency
