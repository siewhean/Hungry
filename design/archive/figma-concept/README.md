# Hungry Figma Concept Board

This folder contains the report-first visual concept board for the Hungry mobile app.

## Files

- `index.html`: the concept board
- `styles.css`: the board styling

## What the board includes

- `00 Product Principles`
- `01 Reference Board`
- `02 Foundations`
- `03 IA + Flows`
- `10 Core Screens`
- `20 Components`
- `30 Prototype`

Because the connected Figma workspace is on the Starter plan, the intended multi-page Figma structure was collapsed into one long board that can be captured into Figma and then reorganized into sections or pages later.

- The concept restores the 4-tab IA from the reports: `Discover`, `Search`, `Reads`, `Profile`.
- Discover absorbs the strongest “social feed” ideas from the current app direction so the app feels alive without breaking the report structure.
- Review remains a dish-attached flow rather than a primary tab in the concept.
