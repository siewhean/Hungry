# Hungry Figma Redesign Source

This folder contains the capture-ready HTML/CSS source for the polished Figma redesign.

Files:

- `direction.html`
- `prototype.html`
- `components.html`
- `styles.css`

Each page includes the Figma HTML-to-design capture script so it can be served locally and imported into the existing Figma file without relying on large `use_figma` scripts.
