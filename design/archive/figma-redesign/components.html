Hungry / 20 Components

Reusable parts for a tighter, warmer, social-native mobile system.

This page holds the smaller-scale UI kit that supports the prototype: bottom navigation, social post cards, map pins, floor chips, dish and stall cards, taste tags, CTA docks, article cards, and review steps. The palette and type sizes follow the frontend guidelines but with more compact application on screen.

Typography

Nunito + DM Mono

Nunito carries UI copy and hierarchy. DM Mono is reserved for price, floor/unit, and low-level metadata.

Shape language

Rounded, but tighter than before

Cards 16–20 radius, sheets 24, more content density, less oversized decorative softness.
