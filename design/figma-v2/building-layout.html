Hungry v2 / 04 Building Layout

Three building directory directions — from floor plan to 3D isometric.

The current BuildingDrillDownScreen uses Badge chips for floor selection and has no building exterior image. The floor "map" is absent entirely — just a list. All three variants fix the floor selector (segmented tab strip, not badge chips), add visual context, and remove the redundant "Open stall menu" button from every row.

Floor selector → tab strip (no Badge chips) Building exterior hero image No "Open stall menu" button in rows Visual floor map SVG 3D isometric option

Current Implementation Audit

What's wrong with BuildingDrillDownScreen.tsx

Issue · Lines 91–97

Floor selector uses Badge chips

Pressing a Badge to select a floor is the exact "unnecessary pill button" pattern the user wants to eliminate. Replaced with a proper underline tab strip in all variants — standard mobile navigation pattern.

Issue · Line 39

"Open stall menu" button inside every pressable card

The entire StallRow card is already wrapped in a Pressable. A Button inside it creates redundant tap targets and visual noise. Removed in all variants — tap the card to open.

Missing feature

No building exterior image or context

Users arriving at a building drill-down have zero visual confirmation they're looking at the right place. A hero photo of the building entrance dramatically reduces disorientation.

Missing feature

No floor plan visual — only a text list

Hawker centres and food courts have spatial layouts. A simplified SVG floor map with stall nodes gives users a mental model of where stalls are — especially useful for first-timers.

The most spatially grounded experience. Building exterior photo at top establishes place. The floor selector is a tab strip — underline indicator, no pill chips. A simplified SVG floor plan shows stall positions. Below: stall rows with thumbnail, name, open dot — no redundant buttons.

  • SVG floor plan with stall node positions

  • Stall rows: thumbnail + name + open dot + hygiene shield

Variant B

Vertical Level Stack

Accordion navigation

Levels as expandable accordion cards — tap to reveal stall grid

Best for buildings with many levels (5+). Instead of a tab strip that gets crowded, each level is a card that expands inline. Users can have multiple levels open simultaneously for comparison. 2-col stall grid inside each level is more compact than rows.

  • Compact building header (no full hero)
  • Each level: expandable accordion card
  • Inside each level: 2-col stall mini-card grid
  • Type filter strip: All / Chinese / Indian / Malay / Western
  • No pill badges — type shown as text in stall card
  • Open/closed: coloured dot only

Variant C

3D Isometric Building Preview

3D visual

Isometric SVG building — tap a floor to highlight it, swipe to stall sheet

The most spatially distinctive approach. An isometric building diagram at the top lets users visually identify floors and tap to select. The active floor is highlighted. A slide-up stall detail sheet appears when tapping a stall node. Works best for mall-style multi-level venues.

  • Isometric SVG building (3D perspective, no extra lib needed)
  • Tap floor in 3D view → that floor highlights + list updates
  • Stall node tap → bottom sheet slides up with stall info
  • Color legend: orange=hawker, teal=café, navy=restaurant
  • Floor indicator: active floor has solid colour fill in iso view
  • No pill badges anywhere — legend uses colored rectangles
