Hungry v2 / 01 Home Feed

Three home feed directions — social without being creator-first.

The current feed uses unnecessary Badge pill labels ("Video", "Photo", "dish tags") and has no visual differentiation between stalls and users. All three variants below fix those issues while exploring different content rhythms. Key constraint: every post action routes back to a dish or stall decision, not to vanity metrics.

No "Video" / "Photo" pills Stall vs User visual differentiation Dish links in-text, not as badge rows Story rail at top Likes count visible

Current Implementation Audit

What's wrong with HomeFeedScreen.tsx

Issue · Line 44

Unnecessary "Video" / "Photo" badge pills

A play icon centered on the media already communicates video. The badge chip adds visual noise with no utility. Removed in all v2 variants.

Issue · Lines 82–87

Dish name badges below every caption

Orange pill row for dish names breaks reading flow and feels like metadata tags. In v2, dish names become inline underlined links within the caption text.

Missing feature

No stall vs user visual differentiation

Stall accounts should have an orange avatar ring + fork icon badge. User accounts have a grey ring. Visually, you can distinguish at a glance who posted.

Missing feature

No story rail, no like counts, no save

Social signals (story rings, like counts, saves) are what make a feed feel alive. Their absence makes the app look like a static list, not a community.

Variant A — Recommended

Appetite Scroll

Recommended

Full-bleed 4:5 cards, story rail, no pill labels

The closest to Instagram in feel but intentionally different in purpose: every element routes to a food decision. Stories at top differentiate stalls (orange gradient ring) vs users (grey ring). Media does all the visual work — no floating type labels.

  • Story rail: orange ring = verified stall, grey ring = user
  • 4:5 image ratio — shows more food, less dead canvas
  • Play icon centered on video (no badge)
  • Heart + count, comment, share, bookmark — minimal action bar
  • Dish names as underlined text links in caption
  • Avatar has fork-icon badge for stall accounts
  • Instagram fix: bookmark moves to far right (not bottom-right of image)
  • Instagram fix: distinct icons — Heart for like, Bookmark for save, never combined

Variant B

Mosaic Grid

Compact discovery

2-column grid with alternating sizes — more content per scroll

Addresses Instagram's single-column monotony critique. Mosaic layout gives more content per screen — good for browse mode. Featured full-width post every 5 cards draws attention. Avatar + name in overlay (not above image) keeps feed clean.

  • 2-col grid, every 5th card is full width (16:9)
  • Avatar + name in overlay at card bottom
  • Like count in corner of each card
  • Stall avatar is orange-tinted; user is neutral
  • Tap card → full post with caption + dish links
  • No pill labels anywhere on the grid
  • Feels more like a food discovery board, less like a social timeline

Variant C

Stories-First with Edge Indicator

High contrast differentiation

Large story strip + left-edge color bar to distinguish stalls from users

Addresses Instagram's problem of everything looking the same. The left edge color bar is the most space-efficient differentiation method: orange bar = stall post, warm cream bar = user post. No pill labels needed. Story strip is larger and more prominent.

  • Large story strip (72px avatars) — more prominent than Instagram stories
  • Left orange bar = stall post (institutional account)
  • Left cream bar = user post (individual)
  • 3:2 image ratio — tighter, less scroll needed per post
  • Inline "View dish" CTA at bottom of post — explicit conversion path
  • Blog/Reads cards surfaced inline as a card type (not a separate tab)
