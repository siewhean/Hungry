Hungry v2 / 03 Stall Detail

Three stall description directions — from editorial to immersive to menu-first.

The current StallDetailScreen exists but has no hero image, no delivery links as visual buttons, and hygiene grade as a plain text badge. All three variants add visual richness while keeping operational trust signals (hours, grade, unit number) close to the hero moment. The "Open stall menu" button inside every card row is removed — the whole card is pressable.

Hero image with gradient Hygiene shield (not badge pill) Delivery icons, not text buttons No redundant CTA inside rows Taste radar chart

Current Implementation Audit

What's wrong with StallDetailScreen + BuildingDrillDown

Issue · BuildingDrillDownScreen Line 39

"Open stall menu" button inside every pressable card row

The card wrapper is already a Pressable. A button inside it adds visual clutter and creates nested tap targets. Removed in all variants — the card tap is the action.

Missing feature

No stall hero image

Stall detail pages open to a plain text block. A 16:9 hero food/stall photo dramatically increases appetite cues and perceived quality of the discovery. All variants add this.

Pill label issue

Hygiene grade as plain Badge chip

The NEA hygiene grade is a trust signal that deserves a more intentional visual treatment. All variants use a shield icon — visually distinct from content labels, never a pill.

Missing feature

Delivery links are missing entirely

Users should be able to order delivery via GrabFood or Foodpanda directly from the stall page. Variant A uses icon buttons. Variants B and C use subtle inline links.

Variant A — Recommended

Editorial Card

Recommended

Hero image → stall info → dish carousel → delivery → reviews

The most direct stall-to-order path. Prioritises food imagery, then surfaces the critical trust signals (grade, hours, unit), then gets to dishes and ordering fast. The sticky bottom bar means "Order / Directions" is always reachable.

  • Full-bleed 16:9 hero with gradient overlay
  • Floating back + share + save icons (no pill labels)
  • Shield icon for hygiene grade — not a badge chip
  • Open/closed status: colour dot + text, no badge
  • Horizontal dish carousel below stall info
  • Delivery icons: Grab, Foodpanda, Deliveroo
  • Taste radar chart (spider chart from reviews)
  • Sticky bottom: "Order delivery" + "Directions"

Variant B

Menu Board

Dish-first layout

Variant C

Immersive Story Format

Visual-first

Full-screen food image → blur scroll-up panel → photo strip → menu

The most visceral first impression. Users see the food as the entire screen first, then scroll down to reveal the stall information. Creates a "magazine cover" effect — great for the feed-to-stall transition from a food photo. Info panel slides up as user scrolls.

  • Full-screen food image as screen background
  • Info panel scrolls up from bottom with blur/frosted glass
  • Photo strip: 5 dish thumbnails horizontally
  • Vertical scroll continues to full reviews + menu
  • Best for premium restaurant contexts
  • Back/share float on image without pills
