# Hungry Website Landing Page Brief — Updated Version

## 1. Project Overview

**Product name:** Hungry
**Website type:** Marketing website + private merchant portal
**Current app status:** Coming soon
**Primary website goal:** Grow early interest, collect waitlist signups, and onboard merchants before public app launch.

Hungry is a Singapore-focused food discovery app that helps people discover nearby food, menus, opening hours, reviews, and hidden gems while helping merchants get discovered by hungry customers around them.

The website should feel like a polished consumer app site with a warm Singapore food identity. It should balance premium and playful, but lean more premium.

---

## 2. Core Positioning

### Main Positioning Statement

> Hungry helps people discover food around them and helps merchants get discovered by nearby hungry customers.

### Original Tagline

> Discover the foodies around you and get hungry!

### Refined Website Hero Direction

For clarity on a landing page, use:

> Discover food around you. Get Hungry.

Supporting line:

> Join the waitlist for Hungry — a Singapore food discovery app built for foodies, hawkers, cafes, restaurants, and local food businesses.

### GitHub Brand Reference

The GitHub design standard positions Hungry around the core idea:

> Find the dish. Not just the restaurant.

This is very strong and should influence the landing page copy. The website should focus on **dish-first discovery**, not just restaurant discovery.

Recommended copy direction:

> Find the dish. Makan nearby.

This can be used as a supporting line, feature headline, or brand statement.

### Landing Page Colour Usage

Recommended visual ratio:

- 55% warm background, white, and cream surfaces
- 25% navy and neutral structure
- 10% Hungry Orange for CTA and active moments
- 5% Amber for ratings, food highlights, and “must try” moments
- 5% green/red for open/closed and status cues

### Website Colour Rules

- Use **Hungry Orange** for primary CTAs.
- Use **Deep Navy** for premium headings.
- Use **Paper Warm / Warm Ivory** for the overall landing page background.
- Use **Hawker Amber** sparingly for food highlights and rating-style visuals.
- Avoid purple, unrelated blue accents, generic SaaS gradients, and over-bright colours.

Version 1 should be a beautiful, fast, mobile-first landing website with merchant onboarding.

- Foodie landing section/page
- Merchant landing section/page
- About page
- Join waitlist flow
- Merchant register interest flow
- Private merchant portal login
- Basic merchant portal/dashboard
- Placeholder app mockups

- Mobile-first responsive design

### Version 1 Does Not Need Yet

- Full public web app
- Public stall pages
- User accounts for foodies
- Public merchant listing pages
- Advanced search
- Full filtering
- Map-first experience
- Reviews system
- Paid merchant placement

## 21. Technical Direction

The website build tool has not been decided yet.

### Recommended Stack Options

#### Option A: Next.js

Best if you want:

```text
Strong SEO
Fast landing pages
Future web app expansion
API routes
Merchant portal integration
Scalable frontend architecture
```

#### Option B: Framer

Best if you want:

```text
Fast polished landing page
Easy visual editing
Good marketing site experience
Less engineering overhead
```

#### Option C: Webflow

Best if you want:

```text
Marketing-first website
CMS pages in the future
Visual editor
Non-technical content updates
```

#### Option D: React/Vite

Best if you want:

```text
Custom frontend
Simple landing page
Developer-controlled experience
Less SEO power than Next.js unless configured carefully
```

### Recommendation

For Hungry, use **Next.js** if you expect the website to eventually contain app-like features, SEO pages, merchant dashboards, and public discovery pages.

Use **Framer** only if the immediate need is a beautiful marketing landing page and you want to move fast without building the full web app yet.
