# Website fonts

`Nunito-Variable.woff2` is a Latin-focused WOFF2 subset of Google Fonts' Nunito variable font (`Nunito[wght].ttf`) at commit `26c5c976d82d50c24a8f0a7ac455e0a7c639c226`.

- Weight axis: 200-900
- Included Unicode ranges: `U+0000-024F`, `U+2000-206F`, `U+20A0-20CF`, `U+2100-214F`, `U+2190-21FF`, `U+2600-26FF`
- SHA-256: `56e0da10611ca44669ce5036beedf61f6d019987c0c0c3dd51c148792e94754a`
- License: SIL Open Font License 1.1; see `OFL.txt`

The source font does not contain Chinese or Tamil glyphs, so those strings continue to use the existing system-font fallback.
