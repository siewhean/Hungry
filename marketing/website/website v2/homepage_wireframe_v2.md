# Hungry Homepage Wireframe v2 — Immersive Scroll Story

## 1. Homepage Role

The homepage is the flagship experience for Hungry.

It should not feel like a static landing page. It should feel like a premium, immersive scroll story that introduces Hungry as a Singapore food discovery app for both foodies and merchants.

The homepage should communicate:

- Hungry is coming soon
- Hungry helps people discover food across Singapore
- Hungry helps merchants get discovered
- Hungry is local, premium, and useful
- Foodies should join the waitlist
- Merchants should register interest

## 2. Homepage Experience Summary

**Experience style:** Immersive scroll story  
**Premium level:** 8/10  
**Playfulness level:** 4/10  
**Motion intensity:** Highly immersive  
**Visual emphasis:** Food photography + app UI + Singapore local atmosphere  
**Cultural cues:** Hawker signage, local dish visuals, kopitiam / hawker atmosphere  
**Business coverage:** Hawkers, restaurants, cafés, home-based businesses  
**Primary motion patterns:** Interactive cards, horizontal carousel, reveal-on-scroll  

## 3. Page-Level Structure

```text
1. Announcement Bar
2. Immersive Hero Scroll Story
3. Built for Foodies and Merchants
4. Why Food Discovery Still Feels Broken
5. Sticky Product Showcase
6. Built for the Way Singapore Eats
7. Merchant Discovery Story
8. Reviews, Rankings, and Community Layer
9. Final Split CTA
10. Footer
```

# Mobile Behaviour

## Mobile Priorities

The immersive site must work beautifully on mobile.

### Mobile rules

- avoid heavy 3D on mobile unless optimised
- use vertical stacking instead of complex desktop split layouts
- interactive cards should become tap-to-expand
- carousels should be swipe-friendly
- sticky phone sections should become shorter and simpler
- CTAs should remain visible and easy to tap

## Mobile CTA Placement

Use repeated CTAs:

- hero CTA
- after audience split
- after merchant section
- final CTA

---

# Accessibility and Performance Notes

## Accessibility

- support reduced motion
- preserve contrast
- no text hidden only in hover states
- make carousels keyboard accessible
- ensure all CTAs are reachable by keyboard
- provide alt text for all images

## Performance

- lazy-load images
- optimise all photography
- use responsive images
- avoid unnecessary 3D libraries unless justified
- limit scroll-triggered animation complexity
- test on low-end mobile devices
