# Playbook: Implementation

## When to use

- New feature
- Bug fix
- Refactor with clear acceptance criteria

## Steps

1. Read `tasks/backlog.md` and identify the exact task IDs.
2. Read the governing design/product doc before changing UI.
3. Implement only the scoped task.
4. Update `tasks/backlog.md` first.
5. Run the Hungry verification bundle when appropriate.
6. Record the evidence in `tasks/verification.md`.
7. Append a short note in `tasks/session-log.md`.

## Required output

- changed files
- task IDs updated
- verification run
- residual risk
