# Roadmap Archive

This directory preserves unique historical plans, audits, prompts and implementation notes that are no longer active.

## Rules

- Archived files are context, not current requirements or release evidence.
- Do not implement directly from an archived file without reconciling it against current code, product policy, `tasks/backlog.md` and `tasks/verification.md`.
- Exact duplicates and reproducible generated output should be deleted rather than archived.
- Move a document here only after its useful active content has been incorporated into the current source of truth.
- Keep original dates and branch/context notes where possible.
- Update references when an active document moves here.

## Current policy override

Historical documents may describe guest browsing, mock-first production behavior, older branch names, public mobile routes or features that are now disabled. Current policy is mandatory authentication, Supabase authority for authentication/shared writes and authenticated read-only Excel fallback for eligible catalog outages only.

Use Git history and closed PRs for code history; do not retain obsolete branches solely as documentation.
