# Excel Source Quality Audit — 2026-06-09

## Scope

Workbook reviewed: `data/Hungry F&B Database.xlsx`

Sheet reviewed: `Sheet1`

Rows reviewed: 35,909

This audit checks whether workbook rows are source-ready for production import. It does not mutate the workbook and does not bulk scrape delivery apps.

## Verdict

The workbook is structurally importable, but it is **not content-accurate enough for production consumer display**.

The largest issues are:

- Every `Image URL` is an Unsplash placeholder, not a stall-specific image.
- Every `Dishes Image URL` is an Unsplash placeholder, not a verified dish image.
- 30,800 rows use generic menu seeds.
- 28,387 rows have fewer than 8 menu items, so the menu is likely partial.
- Delivery-app-derived sources must be quarantined unless licensed or merchant-authorized.

## Source Policy

Use this source priority for correction:

1. Government/open sources for identity, licensing, address, and geospatial facts.
   - `data.gov.sg` APIs are public for testing, with API keys recommended for production workflows.
   - NEA Hawker Centres data is an official source for hawker centre location facts.
2. Merchant-owned websites and menu PDFs/HTML for menu items, prices, opening hours, and merchant-provided images.
3. Official mall and food-court directories for tenant/unit/category verification.
4. Google Places only for place matching, website discovery, ratings/opening-hours enrichment, and photo display via permitted APIs/attribution.
5. Delivery apps only as manual leads unless Hungry has permission/licensing.

Do not bulk copy delivery-app menus/images into the workbook. Grab terms restrict compiling directories, copying platform content, and scraping/data mining. Foodpanda terms restrict copying/reproducing platform trademarks/images/materials and note that vendor menu/photo information on platform listings is not guaranteed complete.

## Required Correction Workflow

1. Keep all current Unsplash URLs marked as placeholders.
2. Add explicit per-row provenance fields before production promotion:
   - menu verification status,
   - menu source URL,
   - menu verified date,
   - image verification status,
   - image rights/license status,
   - image source owner,
   - manual review status.
3. Replace generic menu seeds with operator-owned or official menu sources.
4. Replace images only with merchant/operator-owned images, first-party submitted media, or compliant API display metadata.
5. Use the generated CSV queue to prioritize rows:
   - chains and high-frequency duplicate names first,
   - rows with `official_online_seed` but short menus,
   - all `Cuisine Category Seed` / `category_seed` rows,
   - all image placeholders.
6. Run a manual QA sample before any full import:
   - 50 high-traffic chains,
   - 50 hawker stalls,
   - 50 mall/food-court tenants,
   - all delivery-app-quarantined rows,
   - rows with suspicious or generic source domains.
