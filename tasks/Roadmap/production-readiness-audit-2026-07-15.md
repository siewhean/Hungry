## Status definitions

| Status | Meaning in this audit |
| --- | --- |
| `Ready` | All implementation-plan production criteria are evidenced for the feature, including runtime, performance, recovery, security, accessibility, and operations. No feature in this candidate currently meets this status. |
| `Partial` | A real path exists, but implementation, runtime proof, recovery, performance, security, data, or operations evidence is incomplete. |
| `Prototype` | Demonstration or roadmap implementation exists but is not approved for production exposure. |
| `Disabled` | Deliberately excluded by the current production feature flags or build/route gate. It does not block the MVP while unreachable. |
| `Dead` | Superseded/unreachable code or tooling with no approved production role. Retain/archive until reachability evidence authorizes deletion. |
